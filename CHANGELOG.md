# Changelog

## [1.0.0] - 2026-11-17
### Added
- Initial release of the Selectronic SP PRO Home Assistant custom integration (`selectronic_sp_pro`).
- UI-based Config Flow with automatic Device ID discovery and Options Flow for polling interval and Off-Grid Mode.
- Full suite of power, energy, battery, AC output, status, and fault sensors plus binary sensors.
- Bundled Selectronic brand icons and logos (`brand/icon.png`, `brand/logo.png`).
- HACS and Hassfest GitHub Actions validation workflows.
