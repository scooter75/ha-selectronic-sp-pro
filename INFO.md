# Selectronic SP PRO Integration

Monitor your **Selectronic SP PRO** inverter charger locally in Home Assistant via the **Select.live** gateway.

### Key Highlights
- Automatic device discovery via `/cgi-bin/solarmonweb/devices/`
- Real-time power (`W`), voltage (`V`), current (`A`), frequency (`Hz`), temperature (`°C`), and State of Charge (`%`) sensors
- Lifetime `TOTAL_INCREASING` energy sensors (`Wh`) ready for the Home Assistant Energy Dashboard
- Optional Off-Grid Mode labeling for backup generators
